# BeautyDesk

Оболочка рабочего стола для Windows 11 в духе macOS и Linux: верхняя панель, док, лаунчер и виджеты поверх обычной Windows. Ничего в системе не меняется навсегда — после выхода Windows выглядит как раньше.

*A macOS/Linux-style desktop layer for Windows 11: top bar, dock, launcher and widgets. English is available in Settings.*

## Скачать

**[Последняя версия →](../../releases/latest)**

- `BeautyDesk-…-setup.exe` — установщик. Ставит программу в папку пользователя, права администратора не нужны.
- `BeautyDesk-…-win-x64.zip` — то же без установки: распаковать и запустить `BeautyDesk.exe`.
- `BeautyDesk-…-asus-addon.zip` — дополнение для ноутбуков ASUS (по желанию, см. ниже).

Windows может показать предупреждение «Система Windows защитила ваш компьютер» — у программы пока нет цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

## Что внутри

- **Верхняя панель**: активная программа, точки виртуальных рабочих столов, иконки трея, раскладка, звук, сеть, батарея, часы, «остров» с текущим треком.
- **Док**: закреплённые и запущенные программы, увеличение под курсором, превью окон, перетаскивание, корзина.
- **Лаунчер** по клавише Win вместо меню «Пуск»: поиск по программам и калькулятор — наберите `25*4+3`.
- **Виджеты**, которые ставятся куда угодно: часы, стрелочные часы, календарь, погода, плеер с эквалайзером, питание, монитор железа, спидометр, микшер громкости, буфер обмена, ярлыки, фоторамка, заметка, список дел, таймер, курсы валют, диски, сеть, пятнашки.
- **Горячие углы**: задержите курсор в углу экрана — рабочий стол, все окна, лаунчер или блокировка.
- **Темы**: «Ретро-тех», «Стекло» (тёмное и светлое, с размытием), «Linux-райс». Свою тему можно сделать из копии встроенной.
- **Языки**: русский и английский.

## Как пользоваться

- Ромб в левом верхнем углу — меню: настройки, расстановка виджетов, выход.
- Выйти: меню → «Выйти из BeautyDesk» или **Ctrl+Alt+Q**. Если программа зависла или упала, панель задач Windows вернётся сама.
- Удаление: «Параметры» → «Приложения» → BeautyDesk → «Удалить».

## Дополнение ASUS

Для ноутбуков ASUS: режимы вентиляторов, обороты и порог зарядки в виджете «Питание». Ставится отдельно, потому что драйвер ASUS доступен только с правами администратора, а BeautyDesk их не получает. Подробности — в [addons/asus](addons/asus/README.md).

## Свои виджеты

Виджет — один файл JavaScript. Положите его в `%APPDATA%\BeautyDesk\widgets` (кнопка «Открыть папку» в настройках) и перезапустите BeautyDesk — виджет появится в списке при расстановке.

```js
BD.widget('hello', {
  title: 'Привет',            // название в списке (или ключ перевода)
  sizes: [[2, 2], [4, 2]],    // допустимые размеры в клетках, первый — по умолчанию
  create(body, context) {     // body — элемент виджета, context.options — его сохраняемые настройки
    body.textContent = 'Привет!';
    return {
      update() {},             // раз в секунду, пока виджет видно
      destroy() {},            // виджет убрали со стола
    };
  },
});
```

Данные из своей программы виджет получает через канал данных: программа кладёт `<имя>.json` в `%LOCALAPPDATA%\BeautyDesk\bridge`, виджет подписывается через `BD.bridge('<имя>', ({ value, updatedAt }) => …)`. Команды обратно — `BD.bridgeSend('<имя>', {...})`, они дописываются строками JSON в `<имя>.commands` там же. Так устроено дополнение ASUS.

Сторонний виджет работает с теми же правами, что и встроенные, поэтому ставьте только те, которым доверяете.

## Сборка

Нужен .NET 10 SDK.

```
dotnet publish src/BeautyDesk -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Установщик собирается [Inno Setup](https://jrsoftware.org/isinfo.php) из `installer/BeautyDesk.iss`.

## Требования и ограничения

- Windows 11, 64 бита.
- Загрузка и температура видеокарты — только для NVIDIA; температура процессора не показывается.
- Погода и курсы валют берутся у бесплатных сервисов [Open-Meteo](https://open-meteo.com/) и [open.er-api.com](https://www.exchangerate-api.com/): наружу уходят только название города и код валюты.
- Это ранняя версия: возможны ошибки.
