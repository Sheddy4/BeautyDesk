# Дополнение ASUS для BeautyDesk

Добавляет в виджет «Питание» то, что умеет только драйвер ASUS:

- режимы вентиляторов — у Vivobook и Zenbook «тихий / стандарт / турбо / full speed», у ROG и TUF «тихий / баланс / турбо»;
- обороты вентиляторов процессора и видеокарты;
- порог зарядки батареи: 60, 80 или 100 %.

Без дополнения виджет «Питание» показывает режим питания Windows и батарею — это работает на любом компьютере.

Основано на виджете и сервисе AsusQuick, которые написал один из первых тестировщиков BeautyDesk для своего Vivobook Pro 14X.

## Установка

1. Распакуйте архив дополнения целиком.
2. Запустите `install.cmd` и подтвердите запрос прав администратора. Права нужны только для доступа к драйверу ASUS; сам BeautyDesk их не получает.
3. Добавьте на рабочий стол виджет «Питание».

Удаление — `uninstall.cmd`.

## Требования

- Ноутбук ASUS с драйвером «ASUS System Control Interface» (ставится вместе с MyASUS).
- Если стоит G-Helper или Armoury Crate, режимы переключайте в одной программе — иначе они будут перебивать друг друга.

## Как устроено

`AsusFans.exe` при входе в Windows запускает планировщик заданий с повышенными правами. Дополнение раз в 2 секунды, пока работает BeautyDesk, пишет состояние в `%LOCALAPPDATA%\BeautyDesk\bridge\fans.json`, а команды виджета читает из `fans.commands` рядом. Принимаются только известные режимы и пороги 60/80/100.

Коды устройств ASUS WMI (`root\wmi`, `AsusAtkWmi_WMNB`, методы `DSTS`/`DEVS`):

| Код | Что |
|---|---|
| `0x00120075` | режим ROG / TUF: 0 баланс, 1 турбо, 2 тихий |
| `0x00110019` | режим Vivobook / Zenbook: 0 стандарт, 1 тихий, 2 турбо, 3 full speed |
| `0x00120057` | порог зарядки в процентах |
| `0x00110013`, `0x00110014` | обороты вентиляторов процессора и видеокарты (значение × 100) |

Проверено автором исходного сервиса на Vivobook Pro 14X OLED (N7400PC). Поддержка ROG/TUF добавлена по известным кодам устройств и на таком ноутбуке пока не проверялась.

## Сборка

`build.cmd` собирает `AsusFans.exe` компилятором .NET Framework, который есть в любой Windows 10/11.
